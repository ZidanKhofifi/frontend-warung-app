# 🛒 Kedai Digital Web App (Frontend)

Interface pelanggan dan panel admin untuk memesan makanan secara digital.

## 🎨 Tampilan & UX
* **High-Speed UI**: Menggunakan React & Tailwind CSS.
* **Responsive Design**: Optimal di smartphone maupun tablet kasir.
* **Real-time Status**: Tracking pesanan secara langsung.
* **Modern Icons**: Menggunakan Heroicons (react-icons).

## 🛠️ Teknologi
* **Library**: React.js (Vite)
* **Styling**: Tailwind CSS
* **State Management**: React Hooks (useState, useEffect)
* **HTTP Client**: Axios
* **Icons**: Lucide React / Heroicons

## 📦 Instalasi Lokal
1. Clone repositori frontend.
2. Jalankan `npm install`.
3. Buat file `.env` untuk menghubungkan ke API:
   ```env
   VITE_API_URL = http://localhost:5000/api
